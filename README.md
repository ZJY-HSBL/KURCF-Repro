# KURCF-Repro

Reproducible, transparent implementation of the KUR-CF collaborative filtering algorithm described in *Scientific Reports* (2025).

**Paper:** Zhang et al., [Research on collaborative filtering algorithm based on improved K-means algorithm for user attribute rating and co-rating](https://doi.org/10.1038/s41598-025-96705-0).

> Initial repository scaffold. Source code, tests and benchmark scripts will be added in the next commit. This is an independent implementation, not the authors' official code.
